# Code of Conduct

This project adopts the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct.

The full text is at the link above and at <https://www.contributor-covenant.org>.

## Reporting

Report unacceptable behavior to the maintainers via GitHub issues marked as confidential, or by email to the address listed in the project's GitHub profile.

The maintainers will review and respond as quickly as reasonably possible, and will keep reporter identity confidential.
